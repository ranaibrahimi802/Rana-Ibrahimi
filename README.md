# Rana Ibrahimi — Portfolio

Responsive single-page portfolio.

## Run locally
Open `index.html` in your browser. Keep the `images` folder beside it.

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Work in Progress image mapping
- Branding → `images/brand-identity.webp` (red/cream brand identity board)
- Web development → `images/web-development.webp` (coding workstation)
- English & writing → `images/writing-desk.webp` (notebook and pen)
- Drawing & art → `images/floral-artwork.webp` (black-and-white rose drawing)

All four image files are local project assets; no external image URL is required for these cards.
